# Application de recherche de professionnels de santé
Ce projet à été réalisé dans le cadre d'une auto-formation sur *Angular*, en appliquant la méthode d'apprentissage *Just in time*.
# Description
Il s'agit d'une application web permettant de rechercher des professionnels de la santé en fonction de leur catégorie et leur spécialité.
L'application intègre également un système d'authentification sécurisé permettant à chaque professionnel de:
- Créer son profil personnel et professionnel.
- Mettre à jour ses informations en toute autonomie.

# Stack Technique
* Frontend : Angular
* Backend : Java (Spring Boot)
* Base de données : MySQL
